# OYO — 오요 Live2D 리깅 커미션

OYO(오요)의 Live2D 리깅 커미션 페이지입니다.

## 커미션 페이지

🔗 **[OYO Live2D 리깅 커미션 페이지 바로가기](https://oyo02862-lab.github.io/live2d-commission/)**

## 페이지 구성

- **포트폴리오**: Live2D 모델 쇼케이스 영상
- **리깅 샘플**: 머리 XYZ, 몸 XYZ, 물리 움직임 GIF
- **신청양식**: 문의 내용을 작성하고 복사하거나 TXT 파일로 저장

## 미디어 파일 추가

페이지에 사용할 영상과 GIF는 저장소에 업로드한 뒤 HTML의 미디어 경로를 지정하면 됩니다.

예시 경로:

- 쇼케이스 영상: `videos/showcase-01.mp4`
- 리깅 샘플 GIF: `images/head-x.gif`

영상은 MP4 또는 WebM 형식을 사용할 수 있으며, 리깅 샘플은 GIF를 사용합니다.

## 배포

이 저장소는 GitHub Pages를 통해 배포됩니다.

- 브랜치: `main`
- 배포 폴더: `/(root)`
- 메인 페이지: `index.html`

저장소의 파일을 수정해 `main` 브랜치에 반영하면 GitHub Pages 배포 내용도 갱신됩니다.
